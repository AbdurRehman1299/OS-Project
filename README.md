# Image Processing Scheduler - SJF (Non-Preemptive Algorithm)
The project schedules the processing of multiple images based on their arrival and burst times using the **Shortest-Job First (SJF) Non-Preemptive** scheduling algorithm. It aims to minimize the **average turnaround** and **waiting times**, improving overall system efficiency in image processing.
